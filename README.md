# AI-Driven-IT-Operations

Virtual enterprise IT environment with AD, DHCP, File Server, PowerShell, and AI troubleshooting



\# AI-Driven IT Operations \& System Administration Lab



\## 📌 Project Overview

A comprehensive virtual enterprise IT environment built on Windows Server 2022. This project demonstrates core System Administration skills, including infrastructure design, Active Directory management, network services, file server security, PowerShell automation, and AI-assisted troubleshooting.



\## 🏢 Company Scenario

\- \*\*Name:\*\* Bank

\- \*\*Industry:\*\* Financial Services

\- \*\*Size:\*\* Small Business (8-10 employees)

\- \*\*Departments:\*\* IT, HR, Finance, Sales



\## 🛠️ Technologies Used

\- \*\*OS:\*\* Windows Server 2022, Windows 10

\- \*\*Core Services:\*\* Active Directory (AD DS), DNS, DHCP, Group Policy (GPOs)

\- \*\*File Server:\*\* NTFS Permissions, Share Permissions

\- \*\*Automation:\*\* PowerShell Scripting

\- \*\*AI Layer:\*\* Rule-based data collection and analysis

\- \*\*Hypervisor:\*\* VMware Workstation



\## 📂 Project Structure

\- `01-Project-Planning`: Scenario, requirements, and architecture.

\- `02-Network-Design`: IP addressing and network topology.

\- `03-Windows-Server`: Server specs and roles.

\- `04-Active-Directory`: OUs, Users, Groups, and GPOs.

\- `05-Network-Services`: DHCP Scope and DNS configuration.

\- `06-File-Server`: Shares, NTFS permissions, and access control.

\- `07-PowerShell`: Automation scripts (AD Health, Disk Space, Bulk User Creation).

\- `08-AI-Layer`: AI integration for automated system health analysis.

\- `09-Troubleshooting`: Real-world issues encountered and resolved.

\- `10-Testing`: Verification and test results.

\- `11-Screenshots`: Visual documentation of all phases.



\## 🚀 Key Features \& Achievements

1\. \*\*Centralized Identity Management:\*\* Secure AD environment with department-based OUs and Groups.

2\. \*\*Network Services:\*\* Automated IP assignment (DHCP) and name resolution (DNS).

3\. \*\*Data Security:\*\* Isolated File Server shares using precise NTFS and Share permissions.

4\. \*\*Automation:\*\* PowerShell scripts for daily SysAdmin tasks.

5\. \*\*AI Troubleshooting:\*\* Automated collection of system health (JSON) and rule-based analysis for issues like DNS failure, Disk Space, and Service failures.



\## 🧠 Troubleshooting Highlights

During this project, several real-world issues were encountered and resolved (documented in `09-Troubleshooting`):

\- DHCP Service Restart Failure

\- Backup Destination \& Credential Issues

\- AD OU Deletion Protection

\- GPO Precedence Conflicts
